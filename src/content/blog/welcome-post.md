Это демонстрационная статья. Удалите её — дальше статьи блога правятся в
CMS-портале (или `.md`-файлами прямо в `src/content/blog/`, если вы
разработчик). Каждый файл автоматически становится страницей
`/blog/<имя-файла>/`, попадает в список блога, в RSS-ленту и в `sitemap.xml`.

`.mdx`-файлы тоже поддерживаются — это статьи с компонентами, их правит
разработчик руками, портал их не показывает и не редактирует.

## Как добавить статью

1. Скопируйте этот файл и переименуйте — имя файла станет URL (slug).
2. Заполните frontmatter вверху: `title`, `description`, `date`, `tags`.
   Дату всегда пишите в кавычках, например `date: "2026-01-15"` — без них
   YAML сам превращает дату в объект вместо строки, и сборка падает.
3. Пишите текст в Markdown ниже. Zod проверит frontmatter при сборке.

## Что поддерживает Markdown

Обычный **Markdown**: списки, ссылки, цитаты, изображения. Несколько примеров:

- Маркированные списки
- **Жирный** и *курсив*
- [Ссылки](/contacts/)

> Цитата выделяется акцентной полосой слева — стиль задан в `BlogLayout.astro`.

### Изображения

Картинки статьи кладите в `src/assets/blog/` и вставляйте относительным путём —
тогда Astro сам сделает webp и srcset:

```md
![Подпись](../../assets/blog/01-example.webp)
```

## SEO из коробки

Для каждой статьи автоматически формируются `BlogPosting`-разметка (JSON-LD),
Open Graph и хлебные крошки. Достаточно писать хороший контент.
