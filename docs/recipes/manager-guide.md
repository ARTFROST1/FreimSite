# Памятка менеджеру: кнопки на карточке заявки

> **Шаблон: замените плейсхолдеры `<БРЕНД>` / `<продукт>` и отдайте
> менеджеру заказчика.** Выведено из боевого пайплайна клиентского проекта (2026-08).
> Текст ниже готов к закрепу в рабочей группе (Telegram и MAX); в Telegram
> то же самое стоит отдавать командой `/help` бота — держите тексты
> синхронно.

## Как выглядит заявка

Каждая заявка приходит в группу карточкой:

```
🛋 Новая заявка — <БРЕНД>            ← при авто-отправке добавляется строка
                                       «⏱ Авто-отправка: клиент оставил
👤 Имя (или «Клиент с сайта»)           телефон, но не заполнил детали»
📞 +7 (900) 123-45-67
Тип: <продукт> · Связь: телефон
🎯 По мотивам: <работа из портфолио>   (если клиент пришёл с карточки работы)
💬 Комментарий клиента
📎 3 файла                             (в Telegram — ответами под карточкой)
📊 Аналитика (для владельца: откуда пришёл клиент)
🕒 дата и время · источник: форма|попап
[✅ Квал] [🔝 Целевой] [❌ Отказ]
```

## Текст для закрепа в группе

```
📌 Как работать с заявками

Каждая заявка приходит карточкой: имя, телефон, что нужно, файлы клиента.
Под карточкой — три кнопки.

Позвонили клиенту → нажали одну кнопку:

✅ Квал — дозвонились, человек реально хочет <продукт>:
   обсуждаем детали, сроки, стоимость.

🔝 Целевой — то же, но клиент «горячий»: определился, устраивает
   цена, готов к следующему шагу (замер, договор, предоплата).

❌ Отказ — не наш: ошибся номером, спам, не дозвонились после 3 попыток,
   просят то, что мы не делаем, или это тестовая заявка.

Правила простые:
• одна кнопка на карточку, лучше сразу после звонка;
• передумали — нажмите другую, статус перезапишется;
• не уверены между «Квал» и «Целевой» — ставьте «Квал»;
• тестовые заявки тоже отмечайте, кнопкой «Отказ».

Зачем это нужно: нажатие уходит в Яндекс.Метрику, и реклама учится
приводить таких же клиентов. Без нажатий она не понимает, какие заявки
приносят продажи, и деньги уходят на пустые звонки.

⏱ Пометка «Авто-отправка» на карточке = клиент оставил телефон, но не
дозаполнил форму. Это тёплый лид: он начал заявку, стоит перезвонить.
```

## Пояснения для владельца (в группу не нужно)

| Кнопка | Цель в Метрике | Как используется |
| --- | --- | --- |
| ✅ Квал | `lead_qualified` | воронка: сколько заявок вообще живые |
| 🔝 Целевой | `lead_target` | **ключевая цель для Директа** — на неё оптимизируется реклама |
| ❌ Отказ | `lead_rejected` | чистит статистику, показывает качество трафика по кампаниям |

Что происходит технически (можно пересказать заказчику своими словами):

- Нажатие привязывается к конкретному посетителю сайта по `client_id` из
  карточки и уходит в Метрику через **Offline Conversions API** — окно
  привязки **21 день**, так что жать можно и через день-другой после
  заявки, конверсия всё равно «прилипнет» к визиту.
- Директ, настроенный на цель `lead_target`, обучается именно на тех
  посетителях, которые дошли до денег, — это и есть офлайн-конверсии:
  реклама оптимизируется по итогу звонка менеджера, а не по клику.
- Повторное нажатие той же кнопки цель не задваивает; смена статуса
  перезаписывает подпись под карточкой (кто и когда нажал).
- Если у визита нет `client_id` (клиент не принял cookie-баннер) — цель не
  уйдёт; это нормально, в логах бота видно строкой «нет валидного
  client_id».
