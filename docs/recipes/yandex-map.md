# Яндекс.Карта: три уровня реализации

В стартере готов лучший вариант — `src/components/ui/YandexMap.astro`
(портирован из эталона-каталога). Ниже — почему он такой и когда хватает более простых.

## Уровень 1: iframe (просто, 0 KB JS)

```html
<iframe src="https://yandex.ru/map-widget/v1/?ll={lng}%2C{lat}&z=15&pt={lng},{lat},pm2rdl"
        loading="lazy" ...></iframe>
```
Плюсы: не нужен API-ключ, ноль JS. Минусы: стандартная красная метка, нельзя
кастомизировать, iframe перехватывает скролл страницы на тач-экранах.
Так сделана карта на главной странице эталона-витрины. Подходит: страница
контактов простого сайта.

## Уровень 2: JS API в React-острове (страница контактов эталона-витрины)

`ymaps` API v3 внутри React-компонента с `client:visible`. Даёт кастомную
метку и balloon, но тащит React ради карты. Устаревший подход — уровень 3
делает то же без React.

## Уровень 3: `YandexMap.astro` (эталон-каталог, в стартере) — берите его

Что внутри и зачем (это и есть ценность рецепта):

1. **Ленивая загрузка по скроллу.** IntersectionObserver (`rootMargin: 200px`)
   инжектит `api-maps.yandex.ru` только когда карта почти видна. Экономит
   ~150 KB JS на первой загрузке.
2. **Tap-to-activate guard.** Поверх карты кнопка-оверлей «Нажмите, чтобы
   взаимодействовать» с `touch-action: pan-y`: вертикальный свайп по карте
   скроллит СТРАНИЦУ, а не карту. Активация — явный тап; на десктопе гард
   возвращается при уходе курсора (`pointerleave`, только мышь).
   Drag/scrollZoom/multiTouch выключены до активации.
3. **Трёхступенчатая деградация.** Нет ключа → сразу iframe. API не загрузился
   / упал / не отрендерился за 7 секунд → iframe. Нет JS → `<noscript>` iframe.
   Пользователь НИКОГДА не видит пустой блок. Флаг `settled` гарантирует, что
   поздно приехавший JS API не затрёт уже отрисованный iframe.
4. **Кастомный пин** — inline SVG-капля цвета бренда (prop `markerColor`)
   с белым центром и тенью, остриё точно на координате.
5. **Grayscale через CSS, не JS** (prop `grayscale`). Яндекс пересоздаёт
   тайловую панель при перезагрузке тайлов/смене DPR и теряет JS-фильтры;
   CSS-селектор по подстроке класса `[class*='ground-pane']` применяется
   всегда. Метка в другой панели — остаётся цветной.
6. **ResizeObserver → fitToViewport** — карта не разъезжается при реflow
   сетки/повороте экрана.
7. **SPA-навигация**: скрипт свапается вместе со страницей, инициализация на
   `astro:page-load`; сам скрипт API инжектится максимум один раз (guard по id).

### Использование

```astro
---
import YandexMap from '../components/ui/YandexMap.astro';
---
<div class="h-96 overflow-hidden rounded-xl">
  <YandexMap class="h-full" zoom={16} markerColor="#c2703d" grayscale />
</div>
```
Координаты по умолчанию — из `SITE.geo`. Ключ — `PUBLIC_MAPS_API_KEY` в `.env`
(бесплатный на maps.yandex.ru/dev, лимита хватает малому бизнесу с запасом).
Пусто → компонент честно работает iframe-фолбэком. Одна карта на страницу
(фиксированные id).

`MapSection.astro` стартера уже использует этот компонент.

## Ссылка «построить маршрут»

Рядом с картой полезна прямая ссылка на маршрут (паттерн эталона-каталога):
```
https://yandex.ru/maps/?rtext=~{lat},{lng}
```
